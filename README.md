## Tech

Plain **HTML · CSS · vanilla JS** — 0 KB of framework.

| Concern | Implementation |
| --- | --- |
| Layout | CSS Grid + Flexbox, mobile-first |
| Theme | CSS custom properties; persisted dark/light toggle |
| Motion | CSS keyframes + `IntersectionObserver` reveal; `prefers-reduced-motion` respected |
| Interactions | Scroll-spy nav, count-up stats, hero typewriter, project filter, 3D card tilt, cursor-spotlight, scroll-progress bar, Konami easter egg |
| Background | Layered animated grid + dual radial-blur glow |
| Typography | Inter (body) · Space Grotesk (display) · JetBrains Mono (code/terminal) |
| Accessibility | Skip-to-content link, semantic landmarks, focus-visible states, ARIA labels |
| Hosting | GitHub Pages from `main` branch root |

## Local development

```bash
# Clone
git clone https://github.com/surajnayak-DataBahn/suraj-portfolio.git
cd suraj-portfolio

# Serve (any static server works)
python3 -m http.server 8000
# then open http://localhost:8000
```

No build step, no node_modules, no dependencies.
